ជំនួយ & FAQ

ការណែនាំ និងចម្លើយចំពោះសំណួរចំបង

សំណួរ & ចម្លើយ

តើខ្ញុំប្ដូរ Password យ៉ាងដូចម្ដេច?

ចូលទៅ Settings → ផ្នែក "ប្ដូរ Password" → បំពេញ Password បច្ចុប្បន្ន និង Password ថ្មី → ចុច "ប្ដូរ Password"

តើខ្ញុំប្ដូររូប Profile យ៉ាងដូចម្ដេច?

ចូលទៅ Profile → ចុច "ប្ដូររូបភាព" → ជ្រើសរូបភាពពី Device របស់អ្នក → ចុច "រក្សាទុក"

ខ្ញុំចង់ Upload ឯកសារ — ត្រូវធ្វើអ្វី?

ចូលទៅ Upload → ចុច "ជ្រើសរើសឯកសារ" → ជ្រើសឯកសារ → ចុច "Upload ឥឡូវនេះ"

ខ្ញុំចង់ប្ដូរឈ្មោះ — ត្រូវចូលទីណា?

ចូលទៅ Profile → ផ្លាស់ប្ដូរចន្លោះ "ឈ្មោះ" → ចុច "រក្សាទុក"

ខ្ញុំចង់ប្ដូរ Email — ត្រូវធ្វើអ្វី?

ចូលទៅ Profile → ផ្លាស់ប្ដូរ Email → ចុច "រក្សាទុក"
